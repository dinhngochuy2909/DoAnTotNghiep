# Checklist Đồ Án Tốt Nghiệp: Ứng dụng đa nền tảng quản lý và đặt sân thể thao

### 📑 Giai đoạn 1: Phân tích, Thiết kế & Nghiên cứu lý thuyết (Tuần 1 - 3)
- [ ] Nghiên cứu các công nghệ sử dụng: Flutter, Dart, Laravel, Vue 3, PostgreSQL.
- [ ] Nghiên cứu lý thuyết về Machine Learning và bài toán dự báo nhu cầu.
- [ ] Khảo sát, phân tích yêu cầu nghiệp vụ đặt sân thể thao và xác định phạm vi đề tài.
- [ ] Lập tài liệu đặc tả yêu cầu hệ thống.
- [ ] Thiết kế cơ sở dữ liệu (Vẽ sơ đồ ERD).
- [ ] Thiết kế các sơ đồ UML (Use Case, Activity, Sequence, Class Diagram).
- [ ] Thiết kế kiến trúc tổng thể của hệ thống.

### 💻 Giai đoạn 2: Xây dựng các module nghiệp vụ lõi (Tuần 4 - 9)
- [ ] Khởi tạo dự án, thiết lập CSDL PostgreSQL và môi trường phát triển.
- [ ] Xây dựng Backend (Laravel) để cung cấp REST API.
- [ ] Xây dựng Frontend Web quản trị (Vue 3) và App mobile (Flutter).
- [ ] **Hoàn thiện Module Quản lý sân:** Thêm/sửa/xóa sân, quản lý loại sân, giá, khung giờ và trạng thái sân.
- [ ] **Hoàn thiện Module Khách hàng:** Đăng ký, đăng nhập, quản lý thông tin cá nhân và lịch sử đặt sân.
- [ ] **Hoàn thiện Module Đặt sân:** Tìm kiếm sân, xem lịch trống, đặt sân, hủy đặt sân.
- [ ] **Hoàn thiện Module Thanh toán:** Hỗ trợ thanh toán trực tiếp/QR code và xác nhận giao dịch.

### 🤖 Giai đoạn 3: Machine Learning & Dự báo nhu cầu (Tuần 10 - 12)
- [ ] Thu thập và tổng hợp dữ liệu lịch sử đặt sân (thời gian, loại sân, giá...).
- [ ] Thu thập thêm dữ liệu ngoại cảnh (thời tiết, ngày lễ, sự kiện...).
- [ ] Tiền xử lý dữ liệu (làm sạch, xử lý dữ liệu thiếu, mã hóa đặc trưng).
- [ ] Xây dựng và huấn luyện các mô hình ML (Linear Regression, Random Forest, Gradient Boosting, XGBoost).
- [ ] Đánh giá mô hình (bằng MAE, RMSE, R²) và chọn ra mô hình tối ưu nhất.

### 📊 Giai đoạn 4: Tích hợp AI & Xây dựng Dashboard (Tuần 13 - 14)
- [ ] Đóng gói mô hình ML thành API (sử dụng Python).
- [ ] Tích hợp kết quả dự báo từ ML API vào hệ thống chính.
- [ ] Xây dựng chức năng gợi ý sân/khung giờ thông minh trên App Flutter.
- [ ] Xây dựng Dashboard thống kê (Vue 3) hiển thị: doanh thu, lượt đặt, tỷ lệ sử dụng...
- [ ] Trực quan hóa biểu đồ dự báo nhu cầu sân trên Dashboard để hỗ trợ ra quyết định.

### 🚀 Giai đoạn 5: Kiểm thử, Triển khai & Viết báo cáo (Tuần 15)
- [ ] Kiểm thử (Testing) toàn bộ luồng chức năng, API và kết quả phân quyền.
- [ ] Sửa lỗi (Fix bugs) và tối ưu hóa hiệu năng ứng dụng.
- [ ] Đóng gói toàn bộ hệ thống bằng Docker.
- [ ] Triển khai hệ thống (Deploy) lên môi trường Cloud.
- [ ] Hoàn thiện cuốn báo cáo đồ án với đầy đủ sơ đồ, kết quả thực nghiệm.
- [ ] Chuẩn bị Slide thuyết trình.
- [ ] Hoàn tất hồ sơ bảo vệ đồ án tốt nghiệp.
